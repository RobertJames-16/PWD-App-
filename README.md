# PWD Online Portal (Flutter)

A runnable Flutter starter for the PWD citizen and officer screens. It uses only Flutter's built-in Material library and in-memory sample data; reports reset when the app restarts.

## Run in VS Code

1. Install Flutter and the Flutter extension for VS Code.
2. Open this folder in VS Code.
3. In the integrated terminal, run `flutter pub get` and then `flutter run`.
4. Choose an emulator or connected device when prompted.

The `lib/` folder contains the app entry point, report model/store, shared widgets, and one file for each screen. Demo sign-in accepts any non-empty ID and password. Choose **PWD Officer** or **Citizen** to open that role's dashboard.

## Screens

- Splash
- Login and registration
- Citizen dashboard
- Issue details and media selection
- Location list and map placeholder
- Submission confirmation
- Citizen profile
- Officer dashboard
- Officer status update
- Officer profile

The map and media pickers are labeled demo placeholders. Connect them to a map provider, `image_picker`, and an API/backend for production use.
